## Key formulas
- Closure: 2/7 + 5/8 = 51/56 (stays in Q); contrast 5÷0 undefined.
- Commutative: 2+3=3+2=5; 3/5+2/7 = 2/7+3/5 = 31/35; contrast 5-2=3 ≠ 2-5=-3.
- Associative: (3+2)+5 = 3+(2+5) = 10; (1/2+1/3)+1/6 = 1/2+(1/3+1/6) = 1; contrast (5-3)-1=1 ≠ 5-(3-1)=3.
- Challenge: 2/3+4/5 = 4/5+2/3 → Commutative. (1/2+1/3)+1/6 = 1/2+(1/3+1/6) → Associative. 2/7+5/8=51/56 → Closure.

## Property matrix
| Operation | Closure | Commutative | Associative |
| --- | :-: | :-: | :-: |
| Addition | ✓ | ✓ | ✓ |
| Subtraction | ✓ | ✕ | ✕ |
| Multiplication | ✓ | ✓ | ✓ |
| Division | ✕* | ✕ | ✕ |

*Division fails closure only via the zero-divisor exception.

## Production rules
- Commutative: physically move the **numbers** (`.animate.move_to()`).
- Associative: keep numbers in the same order; move only the **grouping highlight**.
- Closure: move the **result** into/outside the Q container.
- Challenge/"YOUR TURN" scene follows the established series pattern: round "THINK" countdown badge at board centre, dims the whole board except itself; questions live in a bordered box near the bottom.
