# Storyboard — Identities & Inverses: "What Brings You Back?"

**Chapter:** Chapter 1 — Rational Numbers
**Concepts:** Additive Identity, Multiplicative Identity, Additive Inverse, Multiplicative Inverse
**Target duration:** 2:20–2:40
**Core visual idea:** Identity = changes nothing (Addition -> 0, Multiplication -> 1). Inverse = brings you back to a special result (Addition -> 0, Multiplication -> 1).

## Scene flow
1. Intro Card — IDENTITY vs INVERSE cards.
2. Additive Identity — 3/5 + 0 = 3/5, operation-machine visual, a+0=a.
3. Multiplicative Identity — 3/7 x 1 = 3/7, a x 1 = a.
4. Identity Comparison — side by side, "Add 0. Multiply by 1."
5. Additive Inverse — 3+(-3)=0, 2/3+(-2/3)=0, a+(-a)=0.
6. Multiplicative Inverse — 2/7 x 7/2 = 1, a/b x b/a = 1.
7. The Zero Trap — 0 x anything = 0, so 0 has no multiplicative inverse; 1/0 undefined.
8. Your Turn — classify 4 statements as identity or inverse (round THINK timer, whole-board dim, full-space box).
9. Summary — four boxed rules + "IDENTITY: changes nothing / INVERSE: brings you back" + Thank You card.

## Production rule
Identities: the second number visually disappears without changing the original.
Inverses: the two numbers physically move together and collapse into the special result (0 or 1).
