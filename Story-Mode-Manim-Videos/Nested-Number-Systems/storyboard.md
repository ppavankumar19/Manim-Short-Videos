# Storyboard — Nested Number Systems: From Natural to Rational Numbers

**Chapter:** Chapter 1 — Rational Numbers
**Concept:** Natural Numbers → Whole Numbers → Integers → Rational Numbers
**Target duration:** 2:20–2:40
**Core visual idea:** Each new number system expands the previous one by adding numbers that were missing; old numbers are never erased.

## Scene flow
1. Intro Card — title + N→W→Z→Q preview chain.
2. Start With Natural Numbers — 1,2,3,4,5,... inside a labeled container.
3. Natural → Whole — 0 joins the set; N⊂W.
4. Whole → Integers — negatives join; W⊂Z.
5. Integers → Rational — 5=5/1, -3=-3/1, 0=0/1; fractions fill gaps between integers; Z⊂Q.
6. Why Are They Nested? — concentric-circle diagram, N⊂W⊂Z⊂Q.
7. Your Turn — classify 3, 0, -1/2 across the four sets (round THINK timer, whole-board dim, full-space box).
8. Summary — NATURAL → +0 → WHOLE → +negatives → INTEGER → +fractions → RATIONAL, boxed relation, Thank You card.

## Production rule
When expanding a set, never erase the old numbers — transform the old row into the new (larger) row so the same numbers visually persist, with the new ones added.
